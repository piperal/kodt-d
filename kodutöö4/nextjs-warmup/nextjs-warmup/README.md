# What I learned

## What does Next.js provide beyond React alone?
<p>Next.js provides a router, API endpoints and server domponents </p>

## Why does the counter need 'use client'?
<p>Tells the system to render the components on client side, or as a client components</p>

## Where does the code in app/api/message/route.js run?
<p>It runs on the Next.js server</p>

## How is this endpoint similar to an Express route?
<p>Similarly to express you can send and receive data between the backend and frontend. The main difference is the setup proccess</p>

## Why must secrets remain on the server?
<p>So that the user cant inspect the page and find any API keys and such</p>
